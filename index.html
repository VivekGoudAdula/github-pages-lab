Introduction

About This Experiment

Understanding modern version control and deployment.

This project demonstrates the complete process of creating a local Git repository, connecting it to a remote GitHub repository, managing source code and deploying a static website using GitHub Pages. It highlights how developers can publish websites without configuring a separate web server. The experiment provides practical knowledge of version control, remote repository synchronization and modern web deployment practices.

Technology Stack

Tools Behind The Project

Three essential technologies powering this deployment.

🔀

Git

A distributed version control system that tracks modifications, manages project history and enables developers to work with different versions of code.

🐙

GitHub

A cloud-based platform that hosts Git repositories and enables collaboration, code reviews, branch management and project sharing.

🌐

GitHub Pages

A static website hosting service that publishes HTML, CSS and JavaScript projects directly from a GitHub repository.
